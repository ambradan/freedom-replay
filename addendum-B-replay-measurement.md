# Addendum B - Measurement pre-commitments for the planted-record replay analysis

**Drafted 2026-08-23, revised and filed 2026-08-24 as an amendment to the registration, per Section 13, before any replay confirmatory run. This addendum refines measurement definitions, plus one directional expectation for condition E, recorded in point 5. The frozen replay item set, conditions, and coding procedures are unchanged; the freeze manifest is untouched.**

The registration already works this way: I commit contrast directions upfront and fix exact statistics in dated addenda before each phase runs. The companion study disclosed in Addendum A taught me how the replay analysis has to measure, and I record those rules now, before the replay confirmatory runs. These are binding principles: operational choices such as outcome formulas, thresholds, cluster identifiers and multiplicity handling belong to the pre-analysis addendum the registration already promises, frozen before the run.

Condition letters follow the frozen protocol: A is the original record, B a plausible fabrication, C a fabrication that contradicts something visible in the same context window, D no memories, E adds one true sentence about the logging error rate.

1. **Incorporation is judged against condition D, never as an absolute reading of a response:** two of the eight constitution clauses preferred the planted-consistent answer under one forced-choice elicitation with no record present at all, and an analysis blind to that prior would misclassify those cases as incorporation. So for every item the primary behavioral event is a change relative to condition D. I can still report an absolute reading, but only as secondary.

2. **Text-only baselines at the matched level of generality:** any automated or classifier-style analysis of responses gets a text-only baseline first, from the same estimator family and refit at the same rung, whether item, span, or clause. If the internal number does not beat the text baseline at a rung, I make no internal or system-level claim there.

3. **Clustered inference wherever material repeats:** items that share a span or a template are not independent. Confidence intervals therefore resample clusters rather than single items, and I report any per-item sign test as anticonservative.

4. **Cross-clause comparisons are directional only:** each clause has its own elicitation and its own response structure, so effect magnitudes are not comparable across clauses. I read each clause against its own condition-D reference, and I limit cross-clause statements to whether an effect is present and in which direction, never to comparing sizes.

5. **Condition E, direction recorded now:** the expected direction is that the true sentence about the logging error rate reduces incorporation relative to condition C. The exact statistic is fixed in the pre-analysis addendum the registration already promises, before the confirmatory runs. The rationale motivates the direction without deriving it. arXiv 2602.20031 shows that prompting a model with information about the process raises how often it reports detecting a prior concept injection, from 0.3 to 39.9 percent; in that study even an inaccurate process description worked almost as well as the accurate one, so the citation is loose motivation and tests neither logging nor memory incorporation. The companion study found behaviorally, on a different model, that the contradicting record moved the choice log-odds toward the planted answer in 273 of 300 items, the count reported in Addendum A. Whether any of this transfers to the deployed system is exactly what the replay tests. One limitation stands declared: condition E measures the effect of adding this sentence, and by itself it does not separate awareness of the error rate from the effect of adding text about the process.

6. **Blind coding stands:** human coders remain blind per the frozen protocol, and nothing in this addendum reaches them.

Provenance: written after the mechanistic exploratory phase and before any replay confirmatory run.
